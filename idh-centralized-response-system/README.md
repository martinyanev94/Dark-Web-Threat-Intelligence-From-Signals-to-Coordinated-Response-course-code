# Centralized Response System

This is a synthetic, standard-library Python reference prototype for a centralized response workflow.

## Run

```bash
python src/main.py
```

## Test

From the project directory:

```bash
python -m pytest
```

The governance layer demonstrates provenance, retention metadata, role-and-purpose access checks, minimized views, audit events, and privacy-aware evaluation metrics. It does not determine guilt or provide operational access to hidden services.
