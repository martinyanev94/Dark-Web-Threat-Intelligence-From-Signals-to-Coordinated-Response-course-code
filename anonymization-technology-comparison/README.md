# Anonymization Technology Comparison

This synthetic, conceptual project generates a comparison brief for TOR, I2P, and Freenet. It separates technology properties from attribution and intent claims.

Run the generator from this directory:

```text
python src/main.py
```

Run the tests with:

```text
python -m unittest discover -s tests
```

The project contains no network access instructions, real case data, or secrets.
